API Diff Privacy Policy

Last updated: 26 Oct 2026

1. What API Diff does

API Diff is a Chrome extension for developers. It adds an "API Diff" tab to Chrome DevTools. It compares an API's JSON response with a baseline you saved earlier and shows what changed.

2. What information it handles

  • The network requests of the page you are inspecting: the address (URL) and method of each request, its status, and its response. This is web browsing activity and website content. It is read only while the DevTools panel is open and, if you turn on the optional "page capture", on the sites you chose.
  • Responses are read to find JSON data. Responses that are not JSON are looked at only to decide that, and are discarded straight away.
  • Request bodies are read only to recognise the name of a GraphQL operation. They are not saved.
  • API Diff does not read or store your cookies, passwords, form contents or request headers. The only header it uses is the response's content type.

3. Where it is stored

  • Baselines (the responses you choose to save) and your settings are stored in your browser's local extension storage, on your own device. They are not synced to other devices and are not sent anywhere. They are stored unencrypted.
  • Everything else (the list of captured calls, earlier calls kept for the "vs previous call" view, and the list of skipped requests) is held in memory only and is discarded when you close DevTools or reload the panel.
  • An API response can contain any kind of data, including personal data. A baseline you save contains whatever that response contained. Avoid saving baselines of sensitive responses on a shared computer, and delete them when you no longer need them.

4. What API Diff does not do

  • It makes no network requests of its own. The comparison runs on your device.
  • It has no servers, no accounts, no analytics, no advertising and no tracking.
  • We do not collect, sell, share or transfer your data to anyone. The developer cannot see it.

5. Permissions, and why they are needed

  • storage and unlimitedStorage: to save your baselines and settings on your device. A baseline is a full API response and can be large.
  • scripting, activeTab and optional access to websites: only for the optional page capture. The extension has no access to any website when you install it. When you click "Turn on for this site" in the toolbar popup, Chrome asks you to allow access to that site (or domain) only. You can turn it off again at any time.
  • Clipboard: only when you click "Copy diff as Markdown", the text of the comparison is placed on your clipboard.

6. Your control

  • Delete a single baseline with "Clear baseline", or all of them with "Clear all baselines".
  • "Clear captured" empties the list of captured calls.
  • Turn off page capture for a site in the toolbar popup, or on chrome://extensions.
  • Uninstalling the extension deletes everything it stored.

7. Limited Use

The use of information received from web pages by API Diff adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. In particular:

  • The information is used only to provide the extension's single purpose: comparing an API response with a saved baseline.
  • It is not transferred to anyone. (Nothing leaves your device.)
  • It is never used for advertising, including personalised or interest-based advertising.
  • No person reads it. It is not used to determine creditworthiness or for lending.
